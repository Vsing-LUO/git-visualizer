## 本次冻结包含的重要修复

- 统一保护文件、分支、仓库和历史切换前的未保存编辑，修复重复草稿提示、无法保存以及外部变更覆盖风险。
- 修复功能区全屏迁移造成的冲突选择、标签页和手工合并文本丢失。
- 冲突文件不再同时进入普通未暂存/已暂存列表；底层拒绝将冲突文件当作普通修改丢弃。
- 编辑器初始插画界面不再接受 `Ctrl+滚轮` 缩放或显示倍率提示；打开文本文件后仍可缩放。
- 详情页下方“所选提交操作”整栏不再跟随缩放，标题固定为最终确认的 `20.4` 设计字号。
