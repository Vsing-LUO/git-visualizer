# 异步隔离与操作结果

切换仓库和关闭窗口会取消旧会话。快照、历史、差异、树、文件和冲突查询通过会话与请求版本丢弃迟到结果。旧仓库中已完成的 Git 操作保留真实结果，但不能改写当前仓库界面。

普通提交和 amend 的成功后处理传入原写操作 RequestContext；进入完成流程及刷新、工作区重建两个 await 返回后检查同一会话。即使内部方法处理取消并正常返回，调用方也不会继续清空新会话输入、选择或状态。

Git 写操作、恢复点创建/恢复、普通保存和分块暂存共用按仓库路径归一化的进程内锁。结果区分完成、执行前取消、失败、部分完成；操作日志失败不改变 Git 实际成功结果，也不自动重复 Git 写入。恢复中途失败保留安全点、固定归档和执行记录。

这些锁不能阻止外部进程写仓库；文本与恢复流程另有摘要和状态校验。
