GitVisualizer v2.0.0
Windows 10 / 11 · x64

开始使用
双击 GitVisualizer.exe，选择已有的 Git 仓库，即可查看提交历史、管理分支和工作区变更。
程序包含 .NET 运行时，无需另行安装 .NET。远程仓库操作需要网络及相应账户权限。

便携版
先将 ZIP 中全部文件解压到一个普通文件夹，再运行 GitVisualizer.exe。
不要在压缩包预览窗口中直接运行。建议使用较短的路径，例如 D:\GitVisualizer。

安装版
双击 Setup，按照向导选择安装位置和是否创建桌面快捷方式。
安装完成页可选择是否立即运行 GitVisualizer，默认勾选；取消勾选后可稍后从开始菜单启动。
可从 Windows“设置 → 应用”或开始菜单中的“卸载 GitVisualizer”移除安装版。
安装目录内有“卸载 GitVisualizer.exe”，双击并确认即可完全卸载。卸载会永久删除当前用户的应用设置、日志、草稿、恢复点、默认运行缓存和本程序保存的凭据。请先备份需要保留的内容。您的 Git 仓库不会被删除。

更新说明
